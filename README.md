# Ship Map Maker

Небольшое приложение для раскрашивания секторов на карте. Каждая зона задана
отдельным цветом на маске. Левый клик по зоне красит её выбранным цветом,
правый - снимает заливку. Состояние сохраняется между запусками, результат
экспортируется в PNG.

## Требования

- Python 3.10+
- Tkinter
- Pillow
- NumPy

Установка зависимостей:

```shell
pip install pillow numpy
```

```
│   ├── canvas_view.py   # отображение картинки на канвасе
│   ├── image_loader.py  # загрузка изображений и маски
│   ├── schools.py       # парсинг storage/schools.txt
│   ├── ui_theme.py      # настройка ttk-стилей
│   ├── config.py        # все настройки
│   └── paths.py         # пути к файлам проекта
├── run.sh               # запуск на Linux/macOS
├── run.bat              # запуск на Windows

```

## Запуск

Linux / macOS:

```bash
./run-linux.sh
```

Windows:

```shell
run-windows.bat
```

Или напрямую:

```bash
python scripts/main.py
```

## Управление

| Действие | Что делает |
|---|---|
| ЛКМ по зоне | Красит зону текущим цветом |
| ПКМ по покрашенной зоне | Снимает заливку |
| «Выбрать школу» (внизу справа) | Открывает меню школ |
| «Сохранить PNG» | Сохраняет текущую карту в `output/` |
| «Сбросить всё» | Убирает все заливки |

## Формат `storage/schools.txt`

Строки вида `название:hex`, по одной на школу. Пустые строки и строки,
начинающиеся с `#`, игнорируются.

```
Pravda:ff0000
St.Gloriana:00aaff
Kuromorimine:000000
Saunders:00ff00
```

Если файла нет, он будет создан с набором по умолчанию.

## Как подготовить маску

Маска — изображение того же размера, что и основное. Каждая зона залита
своим уникальным цветом (RGB). Чёрный (`#000000`) считается фоном и не
красится. Границы между зонами тоже обычно делают чёрными.

## Настройки

Основные параметры лежат в `scripts/config.py`:

- размеры окна;
- палитра интерфейса и шрифты;
- прозрачность заливки (`ACTIVE_ALPHA`);
- длительность и скорость затухания индикатора сохранения.
